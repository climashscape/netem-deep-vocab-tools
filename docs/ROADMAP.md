# 项目开发路线图 (Development Roadmap)

## 🎯 长期愿景 (Vision)
打造一个**完全本地化、隐私优先、高度可定制**的深度词汇学习平台，不仅限于考研英语，未来将支持多语言和自定义词库，成为终身语言学习者的首选工具。

---

## 🚀 阶段规划 (Phases)

### Phase 1: 核心稳固 (v6.x - 当前阶段)
- [x] **纯静态架构**：移除后端依赖，实现 100% 离线运行。
- [x] **数据本地化**：使用 IndexedDB 存储海量词汇与学习进度。
- [x] **AI 深度解析**：支持自定义 API Key 调用 LLM 进行词义解析。
- [ ] **性能优化**：针对 5000+ 词汇列表的虚拟滚动 (Virtual Scrolling) 优化。
- [ ] **多端适配**：进一步优化 iPad/平板端的响应式布局。

### Phase 2: 交互与体验升级 (v7.x)
- [ ] **离线 TTS 发音**：集成 Web Speech API 或 Android 原生 TTS，实现无网发音。
- [ ] **手写记忆模式**：在移动端支持手写输入单词进行拼写练习。
- [ ] **深色模式增强**：提供更多样化的主题配色（如“护眼绿”、“水墨黑”）。
- [ ] **桌面端 PWA**：优化 Windows/macOS 桌面端的快捷键支持与离线安装体验。

### Phase 3: 社区与扩展 (v8.x)
- [ ] **自定义词库导入**：支持导入 Anki 包 (.apkg) 或 CSV/Excel 格式的自定义单词表。
- [ ] **插件系统**：允许开发者编写简单的 JS 插件来扩展功能（如自定义记忆算法、第三方词典API）。
- [ ] **学习社区 (去中心化)**：基于 WebRTC 或 IPFS 实现点对点的学习小组与打卡分享，无需中心服务器。
- [ ] **多语言支持**：扩展架构以支持日语（N1/N2）、法语、德语等小语种词库。

### Phase 4: 终极形态 (Future)
- [ ] **全脑记忆引擎**：结合图像生成、助记词、词根词缀、发音、例句，构建全方位的记忆钩子。
- [ ] **AR 单词卡**：利用手机摄像头扫描实物，实时显示对应的英文单词与解析。
- [ ] **脑机接口探索**：(画饼) 探索通过脑波状态监测专注度，自动调整复习难度。
